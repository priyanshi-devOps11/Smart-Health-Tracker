## 🚀 Key Features

- [cite_start]**🚶 Step Tracker:** Real-time step counting utilizing the device pedometer[cite: 15, 16].
- [cite_start]**❤️ Heart Rate Monitor:** Innovative BPM detection using the device camera and sensor logic[cite: 15, 16, 46, 50, 51].
- [cite_start]**💧 Hydration Tracker:** Log daily water intake with persistent history and progress charts[cite: 15, 16, 24, 25].
- [cite_start]**😴 Sleep Cycle Manager:** Schedule bedtimes and track sleep duration with persistent session logging[cite: 15, 16, 100, 126, 141].
- [cite_start]**⚖️ BMI Calculator:** Quick health assessment based on user height and weight metrics[cite: 15, 16].
- [cite_start]**📈 Analytical History:** View your health trends over the past week through interactive charts[cite: 24, 100].
